RESPONSE KETIKA LIMIT EXCEEDED:
  HTTP 429
  {
    "status": "fail",
    "message": "Terlalu banyak permintaan. Silakan coba lagi nanti."
  }

  Headers:
  - X-RateLimit-Limit: 10
  - X-RateLimit-Remaining: 0
  - X-RateLimit-Reset: <unix-timestamp>
  - Retry-After: <seconds>

IP TRACKING:
  - Extract dari X-Forwarded-For header (Railway proxy)
  - Fallback ke X-Real-IP header
  - Fallback ke remote address
  - Per unique IP address
